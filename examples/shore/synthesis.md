# Corpus design prompt

Write two short, completely fictional notices for a shore-office operations team. Use eight independently testable records in each. Give each record one stable label, a specific value or accountable role, and a single declarative fact. Include distinct notice periods for shift swaps, leave, and expenses so a retriever can confuse them. Omit payroll appeals even though the requester wants that topic. Avoid personal identifiers. These policies exist only in this demonstration.
