# Release inspection sheet

Use the visual language of a marked-up proof. The signed-off passages and changed quantities are the objects being inspected. Give the map a quiet ink ground, use rust for exceptions and green for verified evidence. Keep Barlow Condensed for the release name, DM Sans for long questions and system monospace for case references. Retain the existing tab order.

A lab notebook would provide space for commentary but bury the cases. A monitoring console would imply live telemetry. A release sheet puts the original and revised text together, supports an editorial redline and gives each exception a direct route to the evidence. Use text labels and underlining alongside color. Allow controls to wrap on mobile. Keep the interaction still while the reviewer reads.
