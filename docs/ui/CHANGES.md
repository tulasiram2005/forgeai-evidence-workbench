# V2 review

The release sheet keeps the original workspaces and adds a procurement build. Reviewers can open a prefilled question or jump to failed cases. The map reports exact counts. The external evaluation strip and comparison table expose how results change on unfamiliar questions. A case includes its status across rounds. In a revision, shared prefix and suffix words remain plain while removed and inserted spans receive semantic markup. Source-dependency actions have space around the original and withheld evidence.

The static site uses the existing locally hosted fonts, restrained ink and paper surfaces, green links and rust exception marks. A narrow viewport wraps the view navigation. Review controls use native buttons, inputs and disclosures. No decorative section numbers or simulated telemetry were added.

The branch workflow captures the evidence, runner, blueprint, blind-review and change-impact views at 360, 768, 1280 and 1728 pixels. The interface-inspection artifact contains before/ and after/ images, axe findings and the Lighthouse report when the browser checks finish.

Scope decisions: the hosted compiler remains deterministic. Local dense retrieval is experimental. The generated validation partition participates in acceptance and is not an independent final test. The 75 external questions include repeated scenario structures; no systematic overlap threshold has been verified. Page extraction is heuristic and does not reconstruct complex PDF tables. This revision does not establish production accuracy, full accessibility compliance, or better free-form model composition.
